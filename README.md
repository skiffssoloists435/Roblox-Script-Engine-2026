## FAQ

### What is XCutors and what does it include?

XCutors is a curated collection of popular Roblox script executors packaged together for Windows users. It includes Volt, Synapse Z, Potassium, Wave, and the xcutorsLoader universal loader that ties them all together.

### Is XCutors safe to download and run?

All files included in the XCutors package are scanned and verified before being made available for download. We recommend running a local component scan after extraction and only downloading from the official GitHub repository.

### Why does my anticomponent flag the XCutors files?

Some anticomponent programs may incorrectly identify script executors as potentially unwanted programs due to their injection capabilities. This is a common false positive and you may need to add an exclusion for XCutors to run it properly.

### Which Windows versions are supported by XCutors?

XCutors is fully compatible with Windows 10 and Windows 11 operating systems. Windows 7 and 8 may work in some cases but are not officially supported or tested by our development team.

### How do I switch between different executors in the collection?

Open the xcutorsLoader application and you will see a menu listing all available executors. Simply click on the executor you want to use and it will load automatically, replacing the currently active one.

### Do I need any special software or libraries installed?

XCutors requires Microsoft Visual C++ Redistributable and .NET Framework which are typically pre-installed on modern Windows systems. The installer will notify you if any dependencies are missing and provide a download link.

### How often is the XCutors package updated?

We aim to release updates promptly whenever Roblox pushes changes that affect executor compatibility. Major collection updates are posted monthly and include bug fixes, performance improvements, and new features.

### Can I contribute scripts or report bugs to the project?

Yes, we welcome community contributions through GitHub Issues for bug reports and Pull Requests for script submissions. Please follow the contribution guidelines outlined in the repository README before submitting.
